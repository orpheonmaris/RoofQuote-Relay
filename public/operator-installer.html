RoofQuote Relay / operator setup

Prepare a client's installation without writing code.

Enter the roofing company's approved details once. This tool prepares a complete, company-specific Google Apps Script file for an assisted installation in the company's own Google account. The owner authorizes Google's permissions. No homeowner messages are enabled during setup.

Operator tool, not a login portal. This page is accessible to anyone who has the URL; it is not password-protected. It does not upload, store, or transmit the form entries. Never enter passwords, homeowner records, payment details, or credentials. Use only after a company has agreed to discuss a limited pilot.

Prepared for this client









This script is for one installation. Keep it in a client-approved private place, not a public GitHub repository. It will start in TEST mode.








How you install it for the client


    

  1. Confirm authorization. Agree on the $250 / 14-day pilot scope (or another signed scope), confirm who monitors inquiries, and document data handling and permissions.
    2. 

  2. Use a supervised session. The client signs into their own Google account. Never request their password or two-factor code.
    3. 

  3. Open Google Apps Script. Guide them to Create new Apps Script project and name it RoofQuote Relay — [Company].
    4. 

  4. Paste the prepared script. In the editor's Code.gs, select all and paste the downloaded or copied script. They do not need to understand or modify it.
    5. 

  5. Authorize once. Select installClientPilot, press Run once, and have the company account owner review Google's actual permission prompts.
    6. 

  6. Verify TEST mode. Copy the CUSTOMER FORM and PRIVATE TRACKER links; submit only a fictional request and confirm both test messages reach the owner. Verify status tracking, report, triggers, timezone, and alerts.
    7. 

  7. Go live separately. Obtain written authorization for the exact company, scope, sender, privacy policy, and customer-facing copy. A specialist then prepares the account-specific go-live change with the owner. Never activate as part of this wizard.
    8. 



What the customer is responsible for


Owning their Google account, reviewing the permissions, approving the emails, monitoring the inbox, contacting their own customers, updating lead statuses, and approving live operation. The vendor handles code preparation, guided setup, and testing.


Why company ownership matters: Google's installable triggers run under the account that creates them. If the vendor created triggers from a vendor account, the automated email sender and long-term ownership would be wrong for this service.
